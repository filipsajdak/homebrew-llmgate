# homebrew-llmgate

Homebrew tap for [llmgate](https://github.com/filipsajdak/llmgate), a gateway that lets Claude Code use any provider, account and model.

```sh
brew tap filipsajdak/llmgate
brew install llmgate
```

`Formula/llmgate.rb` is the `llmgate.rb` asset of the llmgate release of the same version, copied unchanged: its URLs and SHA-256 digests point at that release's archives. It is updated by hand for each release for now.
